How Bedrock detection works

Bedrock serves WordPress core from a subdirectory and content from /app/. This extension reads asset paths such as /app/themes/… and /wp/wp-includes/…, then builds the admin URL as <core>wp-admin/admin.php?page=wpcf7&post=ID&action=edit.

For a default Bedrock install the core path is /wp/, so form links point to https://example.com/wp/wp-admin/…. If your install uses a custom path, set the admin URL above.

Form names come from the Contact Form 7 REST API when you are logged in with permission to edit forms. Otherwise the extension falls back to a nearby heading, a custom aria-label, or the form ID.
